# Série C 2026 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Seed the real 2026 Campeonato Brasileiro Série C as a third national tier that runs in the background, giving the pyramid a floor below Série B.

**Architecture:** Almost entirely seed data. Série C's phase block is the Catarinense's with `rounds` changed from 11 to 19, so `SeedPhaseValidator`, `SeasonCalendarGenerator`, `PhaseResolver` and `FinalClassification` all apply unchanged. The only production-code change is a new `ClimateZone.NORTE` constant. The competition is built up **incrementally** across four authoring tasks — 8 members, then 13, then 17, then 20 — because `SeedPhaseValidator` accepts any `rounds == members - 1`, which keeps every commit green instead of opening a long red window.

**Tech Stack:** Java 21, Spring Boot, JPA, Flyway, Postgres via Testcontainers, JUnit 5, AssertJ, Jackson. Python 3 for the one-off attribute generator.

## Global Constraints

- **Spec:** `docs/superpowers/specs/2026-08-13-serie-c-design.md`. **Research (all field/format facts):** `docs/research/2026-08-13-serie-c-2026-field-and-format.md`.
- **No Flyway migration.** `clubs.climate_zone` is `VARCHAR(20)` with no CHECK constraint, and clubs are created per-save from `clubs.json` at career creation. Nothing in this slice touches schema. **V51 is the highest existing migration; this slice adds none.**
- **Determinism is a hard contract.** All attributes are generated at authoring time and committed as literal JSON. No new runtime RNG.
- **`clubs.json` formatting is one player per line.** Never reserialize the file with `json.dump(..., indent=2)` — that produced a 49,634-line diff once. Splice text, or emit new club blocks in the file's existing compact style.
- **Every Gradle command needs an explicit JAVA_HOME:** prefix every one with `JAVA_HOME=/Library/Java/JavaVirtualMachines/amazon-corretto-25.jdk/Contents/Home`. Docker (OrbStack) must be running for any `*IT` test.
- **Never run `git commit` on a red suite.** Each task ends green.
- **Never run `git add -A`, `git add .`, or `git commit -a`.** A second session shares this working directory and has uncommitted match-engine work in it (`LiveMatchEngine.java`, `MatchSimulationService.java` and their tests). Stage only the exact paths your task names. Never `git stash`, `git checkout --`, or `git reset` a file you did not create.
- **Build contention is expected, not a bug.** The other session runs Gradle against the same `build/` directory. `EOFException`, `NoSuchFileException` or a corrupt-output-file error from Gradle means contention — re-run once before treating it as a real failure.
- Tier calibration target: Série C mean top-11 ≈ **41**; the three existing clubs are fixed at BRU 45.08, FIG 43.79, BAR 42.79, so the **17 new clubs must average ≈ 40.5**.
- Never assert that every Série C club is weaker than every Série B club. It is false today (Brusque 45.1 > Londrina 44.3) and the overlap is deliberate — spec §5.2a.

```java
package br.com.carvoeiromanager.seed;

import org.junit.jupiter.api.Test;

import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.function.Function;
import java.util.stream.Collectors;

import static org.assertj.core.api.Assertions.assertThat;

/**
 * Structural invariants of the club pool that hold no matter how many divisions exist.
 *
 * <p>These are cheap and they have all failed for real. A duplicated shortName (Camboriú and
 * Atlético-MG both wanting CAM) silently makes one club unreachable by every lookup that resolves
 * a club by code. A competition naming a member that is not in the pool fails much later, inside
 * career creation, as a null club id.
 */
class SeedPoolIntegrityTest {

    /** The one club that deliberately plays in no competition at all. */
    private static final String INTENTIONAL_ORPHAN = "HER";

    private final SeedCareer career = new SeedLoader().loadCareer();

    @Test
    void everyShortNameIsUnique() {
        Map<String, Long> counts = career.clubPool().stream()
                .collect(Collectors.groupingBy(SeedClub::shortName, Collectors.counting()));
        List<String> duplicated = counts.entrySet().stream()
                .filter(e -> e.getValue() > 1)
                .map(Map.Entry::getKey)
                .sorted()
                .toList();
        assertThat(duplicated).as("duplicated shortNames").isEmpty();
    }

    @Test
    void everyShortNameIsThreeUppercaseLetters() {
        assertThat(career.clubPool()).allSatisfy(club ->
                assertThat(club.shortName()).as("shortName of %s", club.name()).matches("[A-Z]{3}"));
    }

    @Test
    void everyCompetitionMemberExistsInThePool() {
        Set<String> pool = career.clubPool().stream()
                .map(SeedClub::shortName)
                .collect(Collectors.toSet());
        for (SeedCompetition competition : career.competitions()) {
            assertThat(competition.memberShortNames())
                    .as("members of %s missing from the pool", competition.name())
                    .allMatch(pool::contains);
        }
    }

    @Test
    void noCompetitionListsTheSameClubTwice() {
        for (SeedCompetition competition : career.competitions()) {
            assertThat(competition.memberShortNames())
                    .as("duplicate members in %s", competition.name())
                    .doesNotHaveDuplicates();
        }
    }

    @Test
    void hercilioLuzIsTheOnlyClubOutsideEveryCompetition() {
        Set<String> playing = career.competitions().stream()
                .flatMap(c -> c.memberShortNames().stream())
                .collect(Collectors.toSet());
        List<String> orphans = career.clubPool().stream()
                .map(SeedClub::shortName)
                .filter(s -> !playing.contains(s))
                .sorted()
                .toList();
        assertThat(orphans).containsExactly(INTENTIONAL_ORPHAN);
    }

    @Test
    void everyClubNameAndCommonNameIsUnique() {
        assertThat(career.clubPool().stream().map(SeedClub::name).toList()).doesNotHaveDuplicates();
        assertThat(career.clubPool().stream().map(SeedClub::commonName).toList())
                .doesNotHaveDuplicates();
    }

    @Test
    void everyClubDeclaresAClimateZoneThatParses() {
        // Club.climateZone defaults to SUDESTE, so a missing or misspelled value does not fail —
        // it silently gives the club São Paulo's weather. This is the only thing that catches it.
        assertThat(career.clubPool()).allSatisfy(club -> {
            assertThat(club.climateZone()).as("climateZone of %s", club.name()).isNotBlank();
            assertThatCode(() -> ClimateZone.valueOf(club.climateZone()))
                    .as("climateZone of %s", club.name())
                    .doesNotThrowAnyException();
        });
    }

    @Test
    void everyStateMapsToExactlyOneClimateZone() {
        // Two clubs in the same state on different zones is always a typo. Today the pool is
        // perfectly 1:1 across 13 states; Série C adds AM, MA, PB and SE.
        Map<String, Set<String>> zonesByState = career.clubPool().stream()
                .collect(Collectors.groupingBy(SeedClub::state,
                        Collectors.mapping(SeedClub::climateZone, Collectors.toSet())));
        assertThat(zonesByState).allSatisfy((state, zones) ->
                assertThat(zones).as("zones seen for state %s", state).hasSize(1));
    }
}
```

```python
#!/usr/bin/env python3
"""Turn a compact roster table into clubs.json club objects.

Why this exists: Série C's 17 new clubs need ~370 players. Hand-tuning 28 numbers per player
would mean inventing most of them while presenting the result as researched. Here the NAMES,
POSITIONS and AGES are researched per club; the numbers are derived from a per-club strength
target so the tier lands on its band by construction (spec 5.2).

Mean preservation is the whole trick: each position's offset vector sums to zero, so a player's
mean over all 28 values equals their quality q. The club's top-11 mean therefore equals the mean
of its 11 highest q values, which is exactly what the calibration test measures.

Usage:  python3 tools/seed/generate_squad.py roster.json
Output: one compact JSON object per club on its own line, ready to splice into clubs.json.
"""
import json
import sys

# The 22 authored attributes, in SeedAttributes field order.
ATTRS = [
    "drible", "cruzamento", "cabeceio", "marcacao", "bolaParada", "chuteLonge",
    "visao", "posicionamento", "decisao", "compostura", "concentracao", "determinacao",
    "agressividade", "lideranca",
    "aceleracao", "forca", "resistencia", "equilibrio", "agilidade",
    "posicionamentoGk", "saidaDeGol", "jogoComOsPes",
]
ANCHORS = ["pace", "finishing", "passing", "tackling", "goalkeeping", "stamina"]
KEYS = ANCHORS + ATTRS  # all 28, the set the calibration measure averages over

# Per-position offsets from the player's quality q. Each vector is normalised to sum to zero
# below, so the 28-value mean stays exactly q.
PROFILES = {
    "GK": {"goalkeeping": 34, "posicionamentoGk": 32, "saidaDeGol": 28, "jogoComOsPes": 8,
           "concentracao": 14, "compostura": 12, "lideranca": 8, "forca": 10, "equilibrio": 6,
           "pace": -18, "finishing": -30, "tackling": -20, "marcacao": -22, "drible": -22,
           "cruzamento": -30, "cabeceio": -14, "bolaParada": -24, "chuteLonge": -12,
           "aceleracao": -16, "agilidade": -4, "agressividade": -12},
    "DF": {"tackling": 22, "marcacao": 24, "cabeceio": 18, "forca": 16, "posicionamento": 14,
           "concentracao": 10, "determinacao": 8, "agressividade": 10, "lideranca": 6,
           "equilibrio": 8,
           "goalkeeping": -34, "posicionamentoGk": -34, "saidaDeGol": -34, "jogoComOsPes": -20,
           "finishing": -20, "drible": -14, "cruzamento": -6, "chuteLonge": -8, "visao": -6},
    "MF": {"passing": 20, "visao": 20, "decisao": 14, "resistencia": 16, "compostura": 12,
           "drible": 10, "bolaParada": 10, "chuteLonge": 10, "concentracao": 8, "posicionamento": 8,
           "marcacao": 6, "determinacao": 6, "agilidade": 6,
           "goalkeeping": -34, "posicionamentoGk": -34, "saidaDeGol": -34, "jogoComOsPes": -18,
           "cabeceio": -10, "forca": -8, "finishing": -4},
    "FW": {"finishing": 26, "pace": 20, "aceleracao": 20, "drible": 18, "agilidade": 12,
           "compostura": 10, "cabeceio": 8, "chuteLonge": 8, "cruzamento": 6, "equilibrio": 6,
           "goalkeeping": -34, "posicionamentoGk": -34, "saidaDeGol": -34, "jogoComOsPes": -18,
           "tackling": -22, "marcacao": -24, "forca": -4, "resistencia": -4, "visao": -4},
}

# Squad role -> quality offset from the club's target. Tuned so the top 11 average the target.
ROLE_DELTA = {"starter": 2, "rotation": -3, "fringe": -8}


def _normalised(profile):
    """Return a full 28-key offset map that sums to zero."""
    full = {k: profile.get(k, 0) for k in KEYS}
    drift = sum(full.values()) / len(KEYS)
    return {k: v - drift for k, v in full.items()}


def build_player(entry, target):
    q = target + ROLE_DELTA[entry["role"]]
    offsets = _normalised(PROFILES[entry["group"]])
    values = {k: max(1, min(99, round(q + offsets[k]))) for k in KEYS}
    return {
        "name": entry["name"],
        "position": entry["position"],
        "age": entry["age"],
        "nationality": entry.get("nationality", "Brasil"),
        "positions": entry["positions"],
        "roles": entry["roles"],
        **{k: values[k] for k in ANCHORS},
        "attributes": {k: values[k] for k in ATTRS},
    }


def top11_mean(players):
    means = sorted((sum(p[k] for k in ANCHORS) + sum(p["attributes"][k] for k in ATTRS)) / len(KEYS)
                   for p in players)
    return sum(means[-11:]) / 11


def build_club(spec):
    players = [build_player(e, spec["target"]) for e in spec["roster"]]
    realised = top11_mean(players)
    if abs(realised - spec["target"]) > 1.0:
        raise SystemExit(
            f"{spec['shortName']}: top-11 mean {realised:.2f} misses target {spec['target']} "
            f"by more than 1.0 — adjust the starter/rotation/fringe split")
    club = {k: spec[k] for k in (
        "name", "shortName", "commonName", "nickname", "stadium", "city", "state",
        "climateZone", "stadiumCapacity", "primaryColor", "secondaryColor",
        "formation", "mentality", "pressing", "marking")}
    if spec.get("style"):
```

```java
/**
 * Série C plays itself out in the background over a full season.
 *
 * <p>The load-bearing assertion is the semifinalist one. The real regulation promotes both
 * quadrangular winners AND both runners-up — four clubs, decided in the second phase and not in
 * the final (REC Art. 5º). The engine cannot express quadrangulares, so it runs a seeded knockout
 * over the same eight qualifiers, and the four semifinalists are the four the promotion slice will
 * promote. If that mapping ever stops holding, promotion silently promotes the wrong clubs.
 */
@SpringBootTest
@ActiveProfiles("test")
@Import(PostgresTestContainer.class)
// Needs the real seed: Série C is not in the test profile's trimmed competition set.
@TestPropertySource(properties = "carvoeiro.seed.competitions=")
class SerieCBackgroundSeasonIT {

    private static final int FIRST_PHASE_ROUNDS = 19;
    private static final int MEMBERS = 20;

    @Autowired SaveGameService saveGameService;
    @Autowired UserRepository userRepository;
    @Autowired SeasonAdvanceService seasonAdvanceService;
    @Autowired CompetitionRepository competitionRepository;
    @Autowired CompetitionClubRepository competitionClubRepository;
    @Autowired CompetitionPhaseRepository competitionPhaseRepository;
    @Autowired FixtureRepository fixtureRepository;
    @Autowired StandingsService standingsService;

    @Test
    void serieCPlaysAFullSeasonAndProducesExactlyFourSemifinalists() {
        User user = User.create("seriec_" + UUID.randomUUID(), "hash");
        userRepository.save(user);
        SaveGameResponse save = saveGameService.createCareer(user.getId());
        UUID saveId = save.id();

        Competition serieC = competitionRepository.findBySaveGameId(saveId).stream()
                .filter(c -> c.getName().contains("Série C"))
                .findFirst().orElseThrow();

        // The managed club is not in it — that is what makes it a background competition.
        assertThat(competitionClubRepository.findByCompetitionId(serieC.getId()))
                .hasSize(MEMBERS)
                .noneMatch(cc -> cc.getClubId().equals(save.managedClubId()));

        // Drive the whole season from the managed club's calendar; background rounds resolve as
        // their dates pass.
        while (saveGameService.requireOwned(saveId, user.getId()).getStatus()
                != br.com.carvoeiromanager.career.SaveGameStatus.FINISHED) {
            seasonAdvanceService.advance(saveId, user.getId());
        }

        List<Fixture> fixtures = fixtureRepository
                .findBySaveGameIdAndCompetitionId(saveId, serieC.getId());
        assertThat(fixtures).allMatch(Fixture::isPlayed, "every Série C fixture must be played");

        List<CompetitionPhase> phases = competitionPhaseRepository
                .findByCompetitionIdOrderByOrdinalAsc(serieC.getId());
        assertThat(phases).hasSize(4);

        // First phase: a real 20-row table, everyone on 19 games, goals that balance.
        List<StandingRow> table = standingsService.getStandings(
                saveId, serieC.getId(), phases.get(0).getId(), user.getId());
        assertThat(table).hasSize(MEMBERS);
        assertThat(table).allMatch(r -> r.played() == FIRST_PHASE_ROUNDS);
        assertThat(table.stream().mapToInt(StandingRow::goalsFor).sum())
                .isEqualTo(table.stream().mapToInt(StandingRow::goalsAgainst).sum());
        assertThat(table.stream().mapToInt(StandingRow::goalsFor).sum()).isPositive();

        // The bracket: 8 qualifiers -> 4 quarterfinal ties -> 4 semifinalists.
        Set<UUID> quarterfinalists = clubsIn(fixtures, phases.get(1));
        Set<UUID> semifinalists = clubsIn(fixtures, phases.get(2));
        Set<UUID> finalists = clubsIn(fixtures, phases.get(3));
        assertThat(quarterfinalists).hasSize(8);
        assertThat(semifinalists).as("the four clubs the promotion slice will promote").hasSize(4);
        assertThat(finalists).hasSize(2);
        assertThat(quarterfinalists).containsAll(semifinalists);
        assertThat(semifinalists).containsAll(finalists);

        // The eight qualifiers are the top eight of the first-phase table, not an arbitrary set.
        assertThat(quarterfinalists).isEqualTo(
                table.subList(0, 8).stream().map(StandingRow::clubId).collect(Collectors.toSet()));
    }

    private Set<UUID> clubsIn(List<Fixture> fixtures, CompetitionPhase phase) {
        assertThat(phase.getKind()).isEqualTo(PhaseKind.KNOCKOUT);
        return fixtures.stream()
                .filter(f -> phase.getId().equals(f.getPhaseId()))
                .flatMap(f -> java.util.stream.Stream.of(f.getHomeClubId(), f.getAwayClubId()))
                .collect(Collectors.toSet());
    }
}
```

```java
package br.com.carvoeiromanager.seed;

import org.junit.jupiter.api.Test;

import java.util.Comparator;
import java.util.List;
import java.util.Map;
import java.util.function.Function;
import java.util.stream.Collectors;

import static org.assertj.core.api.Assertions.assertThat;

/**
 * The pyramid has to read as a pyramid. Each tier's mean club strength sits clearly below the one
 * above, measured exactly as the seed authoring measured it: a club's top-11 players by their mean
 * over all 28 attribute values.
 *
 * <p>Deliberately asserted on MEANS, not club by club. Série C's best club is stronger than Série
 * B's worst (Brusque 45.1, Londrina 44.3) and that overlap is correct — a strong third-tier side
 * really is better than a struggling second-tier one, and it is what makes promotion plausible
 * rather than a cliff. A club-by-club domination test would be false today. See spec §5.2a.
 */
class TierCalibrationTest {

    private final SeedCareer career = new SeedLoader().loadCareer();

    private double top11(SeedClub club) {
        return club.players().stream()
                .map(this::playerAverage)
                .sorted(Comparator.reverseOrder())
                .limit(11)
                .mapToDouble(Double::doubleValue)
                .average().orElseThrow();
    }

    private double playerAverage(SeedPlayer p) {
        SeedAttributes a = p.attributes();
        int[] anchors = {p.pace(), p.finishing(), p.passing(), p.tackling(), p.goalkeeping(), p.stamina()};
        int sum = 0;
        for (int v : anchors) {
            sum += v;
        }
        sum += a.drible() + a.cruzamento() + a.cabeceio() + a.marcacao() + a.bolaParada()
                + a.chuteLonge() + a.visao() + a.posicionamento() + a.decisao() + a.compostura()
                + a.concentracao() + a.determinacao() + a.agressividade() + a.lideranca()
                + a.aceleracao() + a.forca() + a.resistencia() + a.equilibrio() + a.agilidade()
                + a.posicionamentoGk() + a.saidaDeGol() + a.jogoComOsPes();
        return sum / 28.0;
    }

    private double tierMean(String competitionName) {
        Map<String, SeedClub> pool = career.clubPool().stream()
                .collect(Collectors.toMap(SeedClub::shortName, Function.identity()));
        List<String> members = career.competitions().stream()
                .filter(c -> c.name().equals(competitionName))
                .findFirst().orElseThrow()
                .memberShortNames();
        return members.stream().map(pool::get).mapToDouble(this::top11).average().orElseThrow();
    }

    @Test
    void theThreeNationalTiersAreOrderedAndClearlySeparated() {
        double a = tierMean("Série A");
        double b = tierMean("Série B");
        double c = tierMean("Série C");

        assertThat(a).as("Série A mean").isBetween(56.0, 60.0);
        assertThat(b).as("Série B mean").isBetween(46.5, 50.5);
        assertThat(c).as("Série C mean").isBetween(39.5, 42.5);

        // The rhythm of the ladder: each step down is a real drop, not a rounding difference.
        assertThat(a - b).as("A over B").isGreaterThan(6.0);
        assertThat(b - c).as("B over C").isGreaterThan(5.0);
    }

    @Test
    void serieCIsNotFlat() {
        // Derived attributes could easily produce twenty identical clubs. The tier needs a real
        // spread, or every promotion race is a coin flip.
        Map<String, SeedClub> pool = career.clubPool().stream()
                .collect(Collectors.toMap(SeedClub::shortName, Function.identity()));
        List<Double> strengths = career.competitions().stream()
                .filter(x -> x.name().equals("Série C"))
                .findFirst().orElseThrow()
                .memberShortNames().stream()
                .map(pool::get).map(this::top11).sorted().toList();

        assertThat(strengths.get(strengths.size() - 1) - strengths.get(0))
                .as("spread between the strongest and weakest Série C club")
                .isGreaterThan(5.0);
    }

    @Test
    void criciumaStillOutranksEverySerieCClub() {
        // The managed club is the strongest in Série B; it must not be seeded into a third tier
        // that could already beat it, or relegation would be meaningless.
        Map<String, SeedClub> pool = career.clubPool().stream()
                .collect(Collectors.toMap(SeedClub::shortName, Function.identity()));
        double cri = top11(pool.get("CRI"));
        List<String> serieC = career.competitions().stream()
                .filter(x -> x.name().equals("Série C"))
                .findFirst().orElseThrow().memberShortNames();
        assertThat(serieC).allSatisfy(s ->
                assertThat(top11(pool.get(s))).as("%s vs Criciúma", s).isLessThan(cri));
    }
}
```
